# 🎧 音频包说明（发音文件放这里）

识字小天地的发音采用**预生成音频包**方案：点页面上的 🔊 按钮，就会播放对应目录里的 mp3 文件。

## 一、目录结构

```
audio/
├── chars/    ← 单字读音，200 个（必须）
│   ├── 水.mp3
│   ├── 火.mp3
│   └── ...
├── words/    ← 组词读音，533 个（可选，不做则点词无声）
│   ├── 喝水.mp3
│   └── ...
└── slow/     ← 慢速单字，200 个（可选）
    └── 水.mp3
```

## 二、命名规范（重要）

**文件名 = 文本本身 + `.mp3`**，不要加序号、拼音或空格：

| 文本 | 正确文件名 | 错误示例 |
|------|-----------|---------|
| 水 | `水.mp3` | `shui.mp3`、`01-水.mp3` |
| 喝水 | `喝水.mp3` | `he_shui.mp3` |
| 星期一 | `星期一.mp3` | `xingqiyi.mp3` |

> 完整清单见项目根目录的 **`识字小天地-音频文件清单.txt`**（也可在页面「📊 学习报告 → 导出音频文件清单」重新下载）。

## 三、三种生成方式

### 方式 1：用自带脚本一键生成（推荐）

```bash
pip install edge-tts
python gen_audio.py              # 生成全部（单字 + 组词），约 5~10 分钟
python gen_audio.py --only char  # 只生成单字（200 个，2 分钟）
python gen_audio.py --slow       # 额外生成慢速版单字
```

脚本会自动跳过已生成的文件，可反复运行；音色在 `gen_audio.py` 顶部的 `VOICE` 处修改。

### 方式 2：自己录音

用手机录音，导出 mp3，按上面的命名规范放入对应目录即可（真人录音对孩子更亲切）。

### 方式 3：其他 TTS 工具

任何能导出 mp3 的中文语音合成工具都行，只要文件名对得上。

## 四、技术参数建议

| 项目 | 建议值 |
|------|--------|
| 格式 | mp3 |
| 采样率 | 16k~24kHz 均可（浏览器通吃） |
| 时长 | 单字 0.5~1 秒，组词 1~1.5 秒 |
| 语速 | 比正常慢一点（约 -10%），方便孩子听清 |
| 音量 | 统一响度，避免忽大忽小 |

## 五、检查与降级

- 页面「📊 学习报告 → 🔍 检测音频包状态」可一键检查 200 个单字音频是否齐全，缺失的会生成清单
- **没放音频也不影响使用**：系统会自动用设备自带的浏览器语音顶上（可在设置里关闭）
- **慢速跟读**：开启后优先播放 `audio/slow/` 里的慢速音频；若没有，会把正常音频降速 0.7 倍播放

## 六、文件体积参考

单个 mp3 约 7~8KB → 全部 733 个文件合计约 **5~6MB**，可直接随项目一起部署到 Vercel / GitHub。
