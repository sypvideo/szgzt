识字小天地 · 部署操作指南

跟着步骤点鼠标，把工作台发布到网上，手机随时能用

预计耗时 10 分钟 · 免费

🗂️ 先认识要上传的文件

你的电脑上有「识字小天地」文件夹，里面只需要上传下面 2 个文件：

📄
index.html
主程序（核心文件）
⚙️
vercel.json
部署配置文件
  • 两个文件都在「识字小天地」文件夹里，已就绪
  • 其余文件（README、指南）不用上传，不影响运行

📦 第一步：上传到 GitHub

GitHub 相当于你的"网盘+仓库"，把工作台代码存进去。

1
创建仓库
浏览器打开 https://github.com/new（没账号先注册，免费）
  • Repository name 填：shizi-200（可自定义英文名）
  • Public / Private 二选一（都免费）
  • 不要勾选 "Add a README file"
点绿色按钮 Create repository
2
上传文件
进入新仓库页面 → 点 Add file → 点 Upload files
💡 把「识字小天地」文件夹里的 index.html 和 vercel.json 拖进上传区
页面下方点 Commit changes，完成上传 ✅
3
确认上传成功
仓库主页应该能看到两个文件列表：index.html 和 vercel.json
⚠️ 如果看不到文件，说明没传上去，重复第 2 步

🚀 第二步：用 Vercel 部署上线

Vercel 是免费托管平台，自动给你的 GitHub 仓库生成一个网址。

1
登录 Vercel 并导入仓库
打开 https://vercel.com → 点 Sign Up → 选 Continue with GitHub（用同一个 GitHub 账号一键登录）
登录后点 Add New… → Project
2
Import 你的仓库
在 "Import Git Repository" 列表里找到 shizi-200 → 点 Import
💡 如果列表里看不到，点列表上方的 Adjust GitHub App Permissions 授权一下即可
3
保持默认配置，直接 Deploy
  • Framework Preset：自动识别为 Other（不用改）
  • Build Command / Output Directory：留空（不用填）
点 Deploy 按钮，等 1 分钟左右
4
部署完成，拿到网址
成功后自动跳到恭喜页面，你的网址类似：
https://shizi-200.vercel.app
点开它，识字小天地就跑起来了 🎉

📱 第三步：手机上使用

1
手机浏览器打开网址
在手机浏览器输入你的 Vercel 网址，即可使用，支持手指描红 ✍️
2
添加到主屏幕（变成 App 图标）
iPhone：Safari 打开网址 → 底部「分享」→「添加到主屏幕」
安卓：Chrome 打开网址 → 右上角「⋮」→「添加到主屏幕」
以后点图标就能直接进入，全屏无浏览器地址栏，体验接近 App

❓ 常见问题

Q：以后改版了怎么更新？

在电脑上改好 index.html，重新拖到 GitHub 仓库覆盖（Commit 一次），Vercel 会在 1~2 分钟内自动重新部署，网址不变。

Q：孩子的学习进度会丢吗？

不会因更新而丢。进度存在"使用设备"的浏览器本地（localStorage），只要不在浏览器里清除网站数据就一直保留。注意：手机和电脑是两套独立进度，互不同步。

Q：Private（私有）仓库能部署吗？

可以，Vercel 免费版支持私有仓库部署，网址仍公开可访问。

Q：部署失败怎么办？

最常见原因：文件没传全（少了 vercel.json 无妨，但 index.html 必须有）。检查 GitHub 仓库是否有 index.html，然后回 Vercel 点 Redeploy（Deployments 页面 → 三个点菜单）。

Q：网址太丑想改？

Vercel 项目 → Settings → Domains，可以添加自定义域名；免费版也可修改项目名来获得新网址（部署后 Vercel 会分配一个 xxx.vercel.app 专属名称）。
